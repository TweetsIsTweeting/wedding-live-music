# 婚禮現場樂團演奏企劃｜Wedding Live Music

這是一個靜態單頁網站，提供婚禮策劃與現場樂團參考演奏曲目及整體風格。

**核心概念：** 優雅、浪漫、明亮、輕鬆的用餐現場演奏。義大利古典與拿坡里歌曲為主，穿插華語、台語經典與輕快流行，營造優雅、浪漫、明亮、輕鬆的用餐氣氛。

## 網頁內容

- 12 首賓客用餐期間的參考演奏曲目
- 2 首特殊用途曲目：結婚進行曲、生日快樂歌
- 希望呈現的音量感受、編曲方向與演奏氛圍
- 手機版響應式設計

## 發布到 GitHub Pages

1. 在 GitHub 建立一個公開 repository，例如 `wedding-live-music`。
2. 將本資料夾的 `index.html`、`styles.css` 和 `README.md` 上傳至 repository 根目錄（不要只上傳 ZIP）。
3. 到 **Settings → Pages**，在 **Build and deployment** 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 `/(root)`，按 **Save**。
5. 待 GitHub Pages 部署完成後，使用 Pages 顯示的網址分享給婚禮策劃與樂團。

本網站不依賴外部套件、圖片或 API；可以直接雙擊 `index.html` 在瀏覽器預覽。

## 曲目備註

原清單中的 `Torna` 與 `Sorrento` 暫合併為 `Torna a Surriento`（重返蘇連多）。如原本想指定兩首不同歌曲，請再核對。

「結婚進行曲」版本（如孟德爾頌或華格納）及演奏時機尚待確認。


## YouTube 參考連結

曲目旁附 YouTube 參考入口。已查得可信官方或表演機構影片者直接連至影片；尚未確認合適單一影片者連至對應 YouTube 搜尋結果，避免提供錯誤影片。搜尋結果不代表最高觀看數或最高評價。

## 修改網站樣式

網頁內容在 `index.html`，視覺樣式集中在 `styles.css`。修改後將兩個檔案放在同一層目錄並上傳 GitHub，GitHub Pages 會自動更新。
